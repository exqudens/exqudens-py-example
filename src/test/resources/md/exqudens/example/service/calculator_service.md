# CalculatorService

The Equated Monthly Installment (EMI) formula used to calculate fixed monthly loan repayments is:

```math

EMI = \frac{P \times R \times (1 + R)^N}{(1 + R)^N - 1}

```

where:

**P** - Principal loan amount (the initial amount borrowed).

**R** - Monthly interest rate (calculated as Annual-Interest-Rate / 12 / 100).

**N** - Total number of monthly installments (loan tenure in years multiplied by 12).
